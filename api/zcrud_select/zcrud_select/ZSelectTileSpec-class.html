ZSelectTileSpec

ZSelectTileSpec class

Surcharge par paramètre (priorité la plus haute) de l'apparence du déclencheur et du modal.

Chaque champ null ⇒ « je ne me prononce pas », et le maillon suivant de la chaîne décide (jeton — trou documenté —, puis référence). Un ZSelectTileSpec() vide est donc rigoureusement équivalent à null (AD-4).
