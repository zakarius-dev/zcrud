ZRichTextToolbarConfig

ZRichTextToolbarConfig class

Configuration granulaire (par bouton) de la toolbar rich-text.

Chaque drapeau active/désactive UN groupe de boutons de la barre. Les présets full/minimal/markdown couvrent les cas parité legacy ; copyWith permet une personnalisation fine par field.
