Construit le champ rich-text (voie ctx/registre) piloté par un ZFieldWidgetContext (field/value/onChanged), SANS ZFormController.

mode fixe la présentation (inline compact vs block aperçu+dialog). ctx.field.readOnly est honoré (rendu lecteur, prioritaire sur le mode). L'assembleur (dispatcher) rend ce widget DANS sa frontière de rebuild value-in-slice : le State persiste (place stable) ⇒ le QuillController n'est jamais recréé (AD-2).
