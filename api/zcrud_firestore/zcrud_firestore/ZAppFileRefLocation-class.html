ZAppFileRefLocation

ZAppFileRefLocation class

Où vit la référence dans le document Firestore.

Type neutre : il ne mentionne aucun type cloud_firestore dans sa surface (la traduction vers FieldPath.documentId est privée).

  • ZAppFileRefLocation.documentId — la référence est l'id du document (chemin de suppression courant chez un hôte legacy) ;
  • ZAppFileRefLocation.field — la référence est la valeur d'un champ (chemin de lecture courant : where('id', whereIn: …), ou une variante par URL distante pour des références en forme d'URL).
