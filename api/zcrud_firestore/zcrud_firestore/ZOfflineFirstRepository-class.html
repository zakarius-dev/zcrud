ZOfflineFirstRepository

ZOfflineFirstRepository<T extends ZEntity> class

Dépôt offline-first synchronisable pour l'agrégat T.

Injection (aucun singleton — testabilité) : un ZLocalStore autoritaire, un ZRemoteStore best-effort, un ZLwwResolver (défaut = résolveur canonique const ZLwwResolver()), une couture de connectivité isConnected optionnelle (défaut null — jamais court-circuitée), et un ZOfflineFirstLog optionnel (défaut no-op).
