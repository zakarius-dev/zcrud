Mapping de valeur AppDocumentStatus legacy (7 valeurs) → ZAppFileUploadState (4 valeurs).

Confinement : la connaissance des valeurs legacy vit ici, jamais dans le domaine. Défensif (AD-10) : une valeur inconnue rend une chaîne inconnue, que ZAppFileUploadState.fromName replie sur pending.

legacy canonique
draft pending
uploading uploading
uploaded, converting, converted, embedding, embedded uploaded
failed failed

Implementation

static String mapDodlpDocumentStatus(Object? raw) {
  if (raw is! String) return '';
  switch (raw) {
    case 'draft':
    case 'pending':
      return ZAppFileUploadState.pending.name;
    case 'uploading':
      return ZAppFileUploadState.uploading.name;
    case 'uploaded':
    case 'converting':
    case 'converted':
    case 'embedding':
    case 'embedded':
      return ZAppFileUploadState.uploaded.name;
    case 'failed':
      return ZAppFileUploadState.failed.name;
    default:
      return raw;
  }
}
