HiveZLocalStore

HiveZLocalStore<T extends ZEntity> class

Adaptateur Hive de ZLocalStore pour l'agrégat T.

Injection (pas de singleton statique — testabilité) : la Box Hive (ou openBox en prod), le kind, le couple (dé)sérialisation typé (fromMap/toMap), une voie de décodage défensive optionnelle (fromMapSafe, ex. ZModelAdapter.fromMapSafe), un ZLocalStoreLog optionnel, une fabrique d'id opaque optionnelle (matérialisation de l'éphémère, AD-14).

Methods

applyMerged(ZSyncEntry<T> entry) → Future<ZResult<Unit>>
Écriture PRÉSERVANT la méta : écrit l'entité et son ZSyncMeta verbatim — updated_at/is_deleted conservés tels quels (jamais now(), contrairement à put). RÉSERVÉ à l'application d'un résultat de merge (défaire l'estampille now() casserait le LWW). Le corps porte toujours son id (invariant clé↔corps). Écrire une entry isDeleted:true propage un tombstone. box.watch() réémet le flux.
clear() → Future<ZResult<Unit>>
Purge physique de tout le cache local (maintenance/tests) — distincte du softDelete métier. À NE PAS utiliser comme voie de suppression d'une entité (celle-ci reste un soft-delete propagé au distant).
dispose() → void
Libère TOUTES les ressources restantes : annule les abonnements box.watch() et ferme les StreamController encore vivants (ceux dont le flux a déjà été annulé se sont auto-libérés via onCancel), puis ferme la box si elle est possédée (_ownsBox, ouverte par openBox).
getAll() → Future<ZResult<List<T>>>
Lit tous les éléments visibles (exclut les soft-deleted). Un store vide renvoie Right(<T>[]) (vide ≠ erreur).
getById(String id) → Future<ZResult<T>>
Lit l'élément d'identité id. Left(ZNotFoundFailure) s'il est absent ou soft-deleted (null ≠ erreur, AD-11).
noSuchMethod(Invocation invocation) → dynamic
Invoked when a nonexistent method or property is accessed.
inherited
purge(String id) → Future<ZResult<Unit>>
Purge physique par identité : box.delete(id), sans tombstone. Idempotent — purger un id absent est un succès.
put(T item) → Future<ZResult<T>>
Persiste item (écrasement JSON total keyé par son id) puis relit l'entrée pour un round-trip fidèle. Note : re-put d'une entité soft-deletée la RESSUSCITE (is_deleted forcé à false par _encode — cohérent avec putMerged, qui préserve le merge LWW).
putMerged(T item) → Future<ZResult<T>>
Écriture PRÉSERVANTE : fusionne la map de item PAR-DESSUS le document brut existant. Une clé présente en base mais absente de item (autre hôte, champ hors-codegen non relu) survit.
restore(String id) → Future<ZResult<Unit>>
Restaure l'élément id soft-deleted (is_deleted = false). id absent → Left(ZNotFoundFailure).
softDelete(String id) → Future<ZResult<Unit>>
Soft-delete l'élément id (is_deleted = true, hors-entité ZSyncMeta). Jamais de purge physique. id absent → Left(ZNotFoundFailure).
syncEntries() → Future<ZResult<List<ZSyncEntry<T>>>>
Voie de lecture de SYNCHRONISATION : renvoie toutes les entrées y compris soft-deletées (tombstones), chacune appariée à son ZSyncMeta. NE PASSE PAS par _isVisible (contraste voulu avec getAll, qui exclut les tombstones — indispensable au merge LWW pour propager une suppression). Décodage défensif (AD-10) : une entrée corrompue/non décodable est écartée + loggée, jamais un throw. Tri stable par id (ordre total). Erreur d'accès → Left(ZCacheFailure).
