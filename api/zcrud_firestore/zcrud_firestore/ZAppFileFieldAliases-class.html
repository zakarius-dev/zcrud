ZAppFileFieldAliases

ZAppFileFieldAliases class

Alias de noms de champs consultés par le mapper par défaut, dans l'ordre : le premier alias présent avec une valeur exploitable gagne.

Les défauts couvrent la forme canonique zcrud (snake_case, cf. AppFile.toMap) et une forme legacy courante (camelCase : name/type/status/cloudUrl/cloudPath). Rien d'autre n'est deviné : tout hôte au schéma différent passe ses propres alias (ou un ZAppFileDocumentMapper complet).
