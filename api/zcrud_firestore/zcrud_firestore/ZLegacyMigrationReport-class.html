ZLegacyMigrationReport

ZLegacyMigrationReport class

Rapport auditable et immuable d'une migration de corpus (migrateCorpus).

Permet un audit sans perte AVANT toute écriture (DRY-RUN) : compteurs cohérents (invariant migrated + alreadyCanonical == total), documents canoniques calculés, census agrégé de préservation métier.
