aboveTabBar

aboveTabBar property

Widget? aboveTabBar
final

Créneau de contexte de page rendu entre l'app-bar et le TabBar — dans le bottom: de l'app-bar, donc dans une zone dont la hauteur est déclarée et qui fait réellement grandir l'app-bar.

  • null (défaut) ⇒ arbre strictement inchangé: le bottom: reste exactement ce qu'il était (le TabBar seul, ou null sans onglets);
  • avec onglets ⇒ Column [aboveTabBar, TabBar] de hauteur préférée égale à la somme des deux;
  • sans onglets ⇒ le créneau devient à lui seul le bottom: de l'app-bar;
  • en mode sliver, il est câblé dans le bottom: de la SliverAppBar: pinned le garde visible au défilement, floating le replie avec l'app-bar.

Ne pas utiliser subtitle pour cet usage. subtitle vit dans le title: de l'AppBar, c'est-à-dire dans la toolbar de 56 dp qui ne grandit pas: mesuré (écran 500×800, mode fixe, 3 onglets), un SizedBox(height: 48) en subtitle laisse l'app-bar à 104 dp et recouvre le TabBar de 10 dp; un SizedBox(height: 96) déborde hors de l'écran par le haut (34 dp de chevauchement). Dans les deux cas zéro exception de layout: le défaut est totalement silencieux et le TabBar reste tapable sous la bande qui le recouvre. Voir _zAppBarBottom.
