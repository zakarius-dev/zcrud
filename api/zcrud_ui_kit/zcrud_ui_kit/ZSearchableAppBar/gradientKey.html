gradientKey

gradientKey property

String? gradientKey
final

Identité opaque et persistante de l'entité ouverte (ex. l'id du dossier), passée à la couture zResolveGradient de zcrud_core — jamais un index de liste, de tri ou de pagination.

Le dégradé n'apparaît que si l'hôte a injecté un ZcrudScope.gradientResolver et que celui-ci rend une spec pour cette clé. Sans injection (ou clé nulle/vide, ou resolver rendant null) le rendu reste sans dégradé : aucun repli dérivé n'est appliqué automatiquement.
