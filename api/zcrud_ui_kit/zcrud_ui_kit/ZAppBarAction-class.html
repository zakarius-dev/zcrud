Constructors

ZAppBarAction({required IconData icon, required String semanticLabel, VoidCallback? onPressed, String? tooltip, bool isOverflow = false})
Construit une action. icon et semanticLabel sont requis (semanticLabel n'est jamais nul — a11y AD-13). onPressed nul ⇒ action désactivée.
const
ZAppBarAction.widget({required Widget child, required String semanticLabel, VoidCallback? onPressed, String? tooltip, bool isOverflow = false})
Variante pour une action portée par un widget (avatar, badge, indicateur de chargement…). Le chemin ZAppBarAction.new à icône reste inchangé.
