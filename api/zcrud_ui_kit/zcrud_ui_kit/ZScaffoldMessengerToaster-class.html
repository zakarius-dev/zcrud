ZScaffoldMessengerToaster

ZScaffoldMessengerToaster class

Toaster par défaut: mappe une ZToastSeverity sur une SnackBar colorée.

Couleur toujours dérivée du ColorScheme courant, JAMAIS de hex (dark-mode-aware — s'adapte au Brightness):

Sévérité Fond (rôle ColorScheme) Texte/icône Icône
error ZcrudTheme.errorColor → scheme.error scheme.onError error_outline
info scheme.primary scheme.onPrimary info_outline
success scheme.tertiary scheme.onTertiary check_circle_outline
warning scheme.secondary scheme.onSecondary warning_amber_outlined

ZcrudTheme/M3 n'exposent pas de slot success/warning/info: le mapping dérive ces sévérités de rôles ColorScheme existants (déterministe, documenté) — aucun littéral introduit. La sévérité est portée par **une icône

  • le texte** (couleur jamais seul canal, invariant AD-13).
