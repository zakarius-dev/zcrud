Le post-filtre effectif quand extra s'ajoute à celui de l'écran : les deux doivent retenir l'entité (conjonction), ou celui qui existe si l'autre est absent, ou null si aucun n'est déclaré.

C'est la règle de cascade des niveaux — écran puis onglet : un niveau ne peut que retirer, jamais rendre ce qu'un autre a écarté.
