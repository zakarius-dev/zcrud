ZExportPolicy

ZExportPolicy class

Politique d'export d'un écran CRUD.

ZCrudScreen<Consignataire>(
  title: 'Consignataires',
  source: ZCrudSource.repository(repo),
  registry: registry,
  export: ZExportPolicy(
    exporters: const <ZListExporter>[ZCsvListExporter(), ZPdfListExporter()],
    onExported: (context, file) => monPartage(file),
  ),
)

Ce que l'écran offre

Un format déclaré = une entrée dans le menu de débordement de l'app-bar (« Exporter (CSV) »), dans l'ordre de déclaration. Une liste d'exporteurs vide n'offre aucune entrée : déclarer la politique sans format ne fait donc rien apparaître, plutôt que d'ouvrir un menu vide.

Ce qui est exporté

Ce que l'écran affiche, et rien d'autre : les lignes réellement listées — tri, filtres, recherche et vue (vivants ou corbeille) déjà appliqués —, avec les colonnes dérivées du schéma et leurs valeurs formatées, telles qu'elles sont peintes. Quand une sélection est en cours, ce sont les seuls éléments cochés qui partent : c'est la lecture attendue d'un geste d'export lancé sélection faite.

N'en font pas partie : la colonne de numéro d'ordre, les cases à cocher de sélection et les boutons d'action. Ce sont des ornements de l'écran, pas des données.

Droits

L'export est une lecture : il ne montre rien de plus que le listing déjà affiché, et n'est donc offert que là où l'écran affiche ce listing — c'est-à-dire quand ZCrudAction.view est accordée. Aucun droit propre à l'export n'est introduit : une application qui veut le restreindre plus finement déclare (ou non) sa politique selon son profil d'utilisateur.
