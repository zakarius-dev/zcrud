ZAppBarActionsContext

ZAppBarActionsContext class

État de l'écran offert à un ZAppBarActionsBuilder — les seules lectures dont une action de barre a besoin, sans couplage à l'état interne.

ZCrudScreen<Bep>(
  title: 'beps',
  source: source,
  actionsBuilder: (state) => <ZAppBarAction>[
    if (!state.isEmpty)
      ZAppBarAction(
        icon: Icons.filter_alt_off_outlined,
        semanticLabel: label(context, 'filters'),
        tooltip: label(context, 'filters'),
        onPressed: _showFilterDialog,
      ),
    if (state.acl.can(ZCrudAction.validate))
      ZAppBarAction(
        icon: Icons.verified_outlined,
        semanticLabel: label(context, 'validate'),
        onPressed: _validate,
      ),
  ],
);
