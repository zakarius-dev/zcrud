Voie repository : lecture, sauvegarde et corbeille passent par les ports neutres de repository (getAll/save/softDelete/restore, listing corbeille via ZDataRequest.deletedScope).

La suppression définitive n'appartient pas au port : elle est offerte si et seulement si le dépôt applique le mixin ZPurgeable (voir supportsPurge).
