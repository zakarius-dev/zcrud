ZDocumentViewerPrefs

ZDocumentViewerPrefs class

Préférences de lecture persistées d'un document (zoom, sens, disposition).

Value object non-ZExtensible : aucun slot extra / extension. Il est décodé défensivement comme sous-modèle de ZDocumentReadingState (chemin sous-modèle : une valeur corrompue — non-map, scalaire… — retombe sur les défauts, jamais de throw du parent, invariant AD-10).
