Reconstruit défensivement depuis une map persistée (invariant AD-10).

Délègue au décodeur généré (défauts sûrs : zoom_level absent/non numérique → kDefaultZoomLevel ; scroll_direction/page_layout inconnus → première constante de leur enum), puis sanitise le zoom — le codegen, lui, ne borne rien.

Corps volontairement non nu : c'est le seul endroit où une valeur persistée corrompue (NaN, -5, 0, 1e9) peut entrer dans le domaine.

Implementation

factory ZDocumentViewerPrefs.fromMap(Map<String, dynamic> map) {
  final base = _$ZDocumentViewerPrefsFromMap(map);
  return ZDocumentViewerPrefs(
    zoomLevel: sanitizeZoomLevel(base.zoomLevel),
    scrollDirection: base.scrollDirection,
    pageLayout: base.pageLayout,
  );
}
