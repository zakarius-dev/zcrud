ZDocumentLearningInfo

ZDocumentLearningInfo class

Qualité d'apprentissage par page d'un document, colocalisée dans l'état personnel ZDocumentReadingState (jamais dans le sous-arbre partageable du document, invariant AD-9).

qualityByPage associe chaque page 1-based à sa qualité entière (ZDocPageQuality.value). Une page absente compte comme « à revoir » : le décompte de maîtrise part de zéro.

Persistance : {"quality_by_page": {"1": 2, "3": 0}} — clés = numéro de page en String (seule forme valide en JSON/Firestore), valeurs = int.
