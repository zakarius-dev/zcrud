zStudyRepositoryProvider<T extends ZEntity> function

Provider<ZStudyRepository<T>> zStudyRepositoryProvider<T extends ZEntity>()

Fabrique le seam d'un ZStudyRepository<T> : un Provider qui throw ZScopeError tant qu'il n'a pas été surchargé (overrideWith) avec un repo concret — jamais de résolution silencieuse (invariants AD-6 « seams throw », AD-10).

L'application hôte crée le seam une fois (final docsRepo = zStudyRepositoryProvider<ZStudyDocument>();) et le surcharge dans son ProviderScope/ZcrudRiverpodScope. Le message d'erreur nomme le Type manquant (cohérent avec ZRiverpodResolver), le rendant actionnable.

Implementation

Provider<ZStudyRepository<T>> zStudyRepositoryProvider<T extends ZEntity>() =>
    Provider<ZStudyRepository<T>>(
      (ref) => throw ZScopeError(
        'Aucun ZStudyRepository<$T> fourni pour le seam Riverpod. Surchargez le '
        'provider retourné par zStudyRepositoryProvider<$T>() via '
        'overrideWith((ref) => monRepoConcret) dans le ProviderScope / '
        'ZcrudRiverpodScope de l\'app.',
      ),
    );
