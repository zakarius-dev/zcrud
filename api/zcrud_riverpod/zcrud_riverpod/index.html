zcrud_riverpod

zcrud_riverpod library

Barrel d'API publique de zcrud_riverpod.

Binding état/injection <-> Riverpod (invariant AD-15) — cible les hôtes Riverpod (lex_douane, IFFD). Fournit ZRiverpodResolver (seam de résolution via ProviderContainer), ZcrudRiverpodScope (scope de binding + ProviderScope) et zFormControllerProvider (provider auto-dispose du ZFormController). Réutilise la réactivité du cœur sans la réimplémenter.

API publique = ce barrel ; implémentation sous lib/src/.
