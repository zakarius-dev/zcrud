ZFontCoverage

ZFontCoverage class

Couverture en points de code d'une police TrueType, lue dans sa table cmap.

Construite par ZFontCoverage.parse, qui rend null sur des octets illisibles plutôt que de lever (AD-10). Exposée publiquement parce qu'un hôte qui doit décider quoi refuser n'a pas à réimplémenter un lecteur de cmap : c'est du code de bibliothèque.

final c = ZFontCoverage.parse(octetsNoto);
c?.covers('م'.runes.first);   // false pour NotoSans-Regular
c?.coversAll('Καλημέρα');     // true
