ZSwipeEmotionIndicator

ZSwipeEmotionIndicator class

Retour émotionnel pendant le drag (présentation pure).

Sous Reduce Motion, l'animation est réellement dégradée, pas seulement désactivée en apparence :

  • sans Reduce Motion : opacité et échelle varient continûment avec offsetPercentage — l'indicateur suit le doigt ;
  • avec Reduce Motion : apparition binaire au seuil (appearThreshold), opacité et échelle fixes, aucune interpolation.

La fonction n'est jamais dégradée, seulement l'animation : au-delà du seuil, l'indicateur apparaît toujours, Reduce Motion ou non. Un utilisateur qui refuse les animations ne perd pas le retour visuel — il perd son interpolation.
