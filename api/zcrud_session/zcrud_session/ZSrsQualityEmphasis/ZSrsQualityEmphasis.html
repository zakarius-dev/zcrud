Construit une affordance. Tous les paramètres sont des dimensions.

  • fillOpacity : opacité du fond d'un cran ordinaire — null : couleur inchangée (fond plein, comportement historique) ;
  • selectedFillOpacity : opacité du fond du cran sélectionné — null : retombe sur fillOpacity ;
  • borderWidth / selectedBorderWidth : épaisseur du bord (<= 0 : aucun bord, comportement historique).
