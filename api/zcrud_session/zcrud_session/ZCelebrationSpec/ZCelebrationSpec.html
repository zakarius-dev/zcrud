Crée une recette de célébration partielle ou complète.

Les bornes ci-dessous reprennent celles que confetti assertionne en interne (durée strictement positive, particules > 0, gravité et fréquence dans [0, 1]). Sans elles, une valeur invalide traverserait cette API publique sans bruit et n'échouerait qu'au fond du paquet tiers, avec un message sans rapport avec le préréglage fautif. Échouer ici nomme le vrai coupable — et null reste toujours licite : il signifie « garde le défaut historique ».
