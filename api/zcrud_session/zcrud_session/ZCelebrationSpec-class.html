ZCelebrationSpec

ZCelebrationSpec class

Recette visuelle optionnelle de la célébration du résumé.

Chaque champ null conserve explicitement le comportement historique. La valeur est donc additive : une application peut ne surcharger qu'un détail sans toucher aux autres réglages.
