ZChatConversationView

ZChatConversationView class

Rend la conversation d'un ZChatController — zéro dépendance tierce.

Sans ZChatRendererScope au-dessus, cette vue est utilisable seule : c'est le défaut fonctionnel qu'exige tout port de rendu de ce paquet.
