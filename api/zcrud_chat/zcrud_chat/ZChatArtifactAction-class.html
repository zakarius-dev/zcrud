ZChatArtifactAction

ZChatArtifactAction class

Un verbe offert sur un artefact : sa condition de visibilité, sa teinte facultative, et son rappel.

Le libellé vient soit d'un texte déjà localisé par l'hôte (label), soit d'une clé du socle (labelKey) résolue par zChatLabel — même contrat que ZChatModelOption. Les cinq constructeurs nommés posent la clé du socle correspondante : un hôte obtient un menu localisé sans alimenter quoi que ce soit.
