Construit une sélection vide et inactive.

activeController : pilotage externe du mode — null signifie que la sélection se gouverne seule (comportement par défaut). Fourni, il devient la source de vérité de active : aucun miroir n'est conservé ici (cf. ZDisplayStateBinding), donc les deux états ne peuvent pas diverger. begin et clear écrivent à travers lui, et ChangeNotifier.notifyListeners est émis dans les deux sens.

Le contrôleur doit être possédé hors de build (ZDisplayStateOwnerMixin) — la même règle que pour cette sélection elle-même et pour ZChatGroupExpansion : un contrôleur créé dans build est inerte dès le premier rebuild.

Implementation

ZChatConversationSelection({ZToggleController? activeController}) {
  _activeBinding = ZDisplayStateBinding<bool>(
    consumer: this,
    initialValue: false,
  )..bind(activeController);
  _activeBinding.listenable.addListener(_onActiveChanged);
}
