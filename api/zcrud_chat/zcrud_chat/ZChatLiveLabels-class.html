ZChatLiveLabels

ZChatLiveLabels class

Libellés optionnels des jalons d'un tour — tous nullables.

Objet de valeur immuable, injecté dans ZChatController à la construction. Il n'a ni BuildContext ni locale : l'hôte le construit à partir de sa propre localisation et le reconstruit si la langue change.
