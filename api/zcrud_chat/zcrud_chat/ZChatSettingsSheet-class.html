ZChatSettingsSheet

ZChatSettingsSheet class

Rend les réglages de génération d'un ZChatSettingsController — zéro dépendance tierce, aucune couleur, aucun libellé en dur.

Utilisable telle quelle (aucun builder n'est requis), et branchée au créneau tools de ZChatComposer : c'est le chemin par lequel les réglages atteignent réellement ZChatController.send(settings:, corpusScope:).
