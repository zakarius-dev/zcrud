ZChatComposer

ZChatComposer class

Rend la zone de saisie d'un ZChatController — zéro dépendance tierce.

Le widget est monté par les deux surfaces (ZChatConversationView et ZChatNotebookView) par une fabrique unique, exactement comme la tuile de message : une régression ici affecte les deux.
