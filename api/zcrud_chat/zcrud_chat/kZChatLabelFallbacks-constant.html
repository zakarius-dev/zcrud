kZChatLabelFallbacks top-level constant

Map<String, String> const kZChatLabelFallbacks

Repli lisible de chaque clé — jamais prioritaire sur l'hôte.

La langue est le français, comme le reste des replis du dépôt : deux conventions de repli dans un même socle multi-consommateurs coûteraient plus qu'une langue de secours unique. L'hôte qui traduit passe ZcrudScope(labels:) — le repli n'est jamais atteint dans ce cas (label() ne le consulte qu'en dernier ressort).

Cette table couvre exactement l'ensemble de kZChatLabelKeys — jamais une inclusion partielle.
