ZChatArtifactSpec

ZChatArtifactSpec class

La déclaration d'un artefact : une clé opaque, un glyphe, un libellé, trois lectures d'état, et des verbes.

Annotations
  • @immutable

Constructors

ZChatArtifactSpec({required String key, required String label, IconData? icon, required ZChatArtifactPresence presence, ZChatArtifactCount? count, ZChatArtifactBusy? busy, Color? accent, List<ZChatArtifactAction> actions = const <ZChatArtifactAction>[]})
Déclare un artefact. Seuls key, label et presence sont requis : un artefact sans verbe est un indicateur d'état, ce qui est une déclaration légitime ; un artefact sans icon est rendu par son label.
const
