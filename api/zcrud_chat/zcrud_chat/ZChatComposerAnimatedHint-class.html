ZChatComposerAnimatedHint

ZChatComposerAnimatedHint class

Le placeholder animé, porté en widget pur — à monter dans le créneau hint de ZChatComposer (visible seulement quand la saisie est vide, la visibilité restant l'affaire du composer).

Les hints sont des textes déjà localisés par l'hôte — typiquement des suggestions de saisie, une donnée métier que le socle ne connaît pas.

Reduce Motion

Sous MediaQuery.disableAnimations : aucun minuteur n'est créé, le premier libellé reste figé.

Rotation déterministe

Aucun Random : la rotation est séquentielle ((i + 1) % n).
