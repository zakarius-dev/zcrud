ZChatSettingsScaleTile

ZChatSettingsScaleTile class

Tuile GÉNÉRIQUE « échelle discrète » : un axe d'HÔTE (niveau de connaissance, sévérité, …) rendu avec la même primitive que les cinq familles — donc la même emphase, la même sémantique, les mêmes cibles 48 dp.

L'état de l'axe appartient à l'HÔTE (selectedKey/onSelect) : le socle n'a nulle part où ranger une valeur métier de « niveau utilisateur ». Chips plutôt que slider : cibles ≥ 48 dp, aucune dépendance de rendu tierce.
