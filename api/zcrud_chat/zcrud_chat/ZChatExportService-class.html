ZChatExportService

ZChatExportService class

Produit un document exportable à partir d'une conversation.

Sans couture, les quatre formats textuels sont pleinement fonctionnels : c'est le défaut zéro-dépendance de ce paquet. Le PDF exige ZChatPdfComposer, le partage exige ZChatExportSink — et leur absence est un Left explicite.
