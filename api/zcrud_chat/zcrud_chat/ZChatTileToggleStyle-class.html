ZChatTileToggleStyle

ZChatTileToggleStyle class

Style du bouton de dépli d'une tuile : sa forme, son alignement, son remplissage.

Tout champ null prend la valeur de référence — celle d'une pilule pleine et centrée. Le style ne s'applique qu'à une tuile dont la coquille est déclarée : sans coquille, le bouton reste le texte aligné au début qu'il a toujours été.
