ZChatSettingsSlot class

Ce que le socle offre au builder d'une tuile de réglage.

Un objet, pas une liste d'arguments — même arbitrage que ZChatComposerSlot : un réglage de plus deviendra un champ de plus ici, jamais un paramètre de plus dans la signature du builder, donc jamais un hôte cassé.
