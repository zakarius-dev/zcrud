ZChatNotebookReference

ZChatNotebookReference class abstract final

Les valeurs de référence du rendu notebook — le point d'audit unique.

Modifier une valeur ici change le défaut du skin partout ; ajouter une couleur ici, et nulle part ailleurs, reste dans le cadre de l'exception encadrée (cf. le dartdoc de bibliothèque).
