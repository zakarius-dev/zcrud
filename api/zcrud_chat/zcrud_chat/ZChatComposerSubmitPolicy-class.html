ZChatComposerSubmitPolicy class

La politique de raccourci clavier d'un composer.

Défaut : Entrée soumet, Maj+Entrée et Ctrl+Entrée insèrent une nouvelle ligne, et rien de tout cela ne s'applique sur une plateforme tactile.
