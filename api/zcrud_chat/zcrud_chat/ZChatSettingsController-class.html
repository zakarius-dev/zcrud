ZChatSettingsController

ZChatSettingsController class

Porte les réglages de génération choisis par l'utilisateur, en tranches réactives granulaires.

Ni créé ni disposé par un widget : son cycle de vie appartient à l'hôte (invariant AD-2), comme celui de ZChatController. Le rendu par défaut est ZChatSettingsSheet ; la valeur courante rejoint la requête par ZChatController.send(settings:, corpusScope:) — chemin que le composer câble pour l'hôte lorsqu'on lui passe ce contrôleur.
