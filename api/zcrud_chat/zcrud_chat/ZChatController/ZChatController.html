Construit un contrôleur.

streamPort et actionExecutor sont les ports de l'hôte ; confirm est le seam de confirmation ; newRequestId fabrique les identités ; buildRequest traduit une saisie en requête de génération.

maxResumeAttempts borne la reprise d'un flux subi (jamais d'une annulation volontaire). 0 la désactive.
