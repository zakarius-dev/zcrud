ZReminderRecurrence

ZReminderRecurrence class

Récurrence de rappel couvrant les deux familles temporelles.

Les deux peuvent coexister : leur combinaison est un ou — le rappel se déclenche si l'une ou l'autre correspond. C'est le comportement attendu d'un utilisateur qui demande « tous les lundis, et la veille ».
