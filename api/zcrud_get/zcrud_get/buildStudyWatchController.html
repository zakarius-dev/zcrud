Fabrique de résolution PAR SEAM d'un ZStudyWatchController.

Résout ZStudyRepository<T> via le resolver (typiquement le ZGetResolver/ get_it du ZcrudGetScope). Si aucun repo n'est enregistré pour ce type, la résolution throw un ZScopeError actionnable contenant le Type manquant (contrat de ZGetResolver, invariants AD-6/AD-10) — jamais null silencieux ni repli sur un repo par défaut.

La spécialisation typée (buildStudyWatchController< UneEntite>(resolver)) est un one-liner laissé à la charge de l'application hôte — le binding reste générique sur T.
