ZCascadeEdge

ZCascadeEdge class

Arête déclarative d'une relation de cascade parentKind → childKind.

Tous les champs sont des String littérales — aucun Type, aucun générique (invariant AD-3). L'arête ne connaît aucun chemin Firestore : la topologie concrète (plate/imbriquée) est résolue ailleurs, à partir du seul childKind.

Constructors

ZCascadeEdge({required String parentKind, required String childKind, required String childParentRef, required String owner})
Déclare une arête parentKind → childKind, où childParentRef est le champ FK côté enfant (ex. 'folder_id', 'parent_id') utilisé en topologie plate pour retrouver les enfants d'un parent, et owner est le paquet propriétaire unique de l'arête (ex. 'zcrud_document').
