ZColorPalette

ZColorPalette class

Registre borné et ordonné de colorKey (String) + remap déterministe d'une clé inconnue. Zéro couleur : le kernel ne porte que des clés sémantiques String — la résolution concrète colorKey → Color vit dans zcrud_core (ZcrudScope.colorKeyResolver).

Immuable, const-constructible, ==/hashCode structurels.
