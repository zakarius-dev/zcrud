int best
final

Record historique de current.

Maintenu à max(best, current) par zAdvanceStreak — la seule voie d'avancement. Portée honnête : fromMap ne renforce pas best >= current (elle ne fait que plancher les négatifs à 0) — une map corrompue est reconstruite telle quelle, pour préserver le round-trip zéro-perte (le constructeur est const, il ne peut rien normaliser ; le forcer ici casserait fromMap(toMap(x)) == x). Un best < current persisté est inoffensif (le badge affiche un record minoré, aucune exception) et se répare seul au premier zAdvanceStreak.
