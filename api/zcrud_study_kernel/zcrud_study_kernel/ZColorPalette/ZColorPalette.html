Construit une palette injectable — pas verrouillée aux clés d'une application particulière.

keys doit être non vide et contenir fallbackKey (garde-fou assert en debug ; en mode release, un keys vide ne fait jamais throw : resolveKey renvoie alors fallbackKey tel quel — invariant AD-10). Constructeur non-const (l'assert keys.contains(fallbackKey) n'est pas une expression constante) — utiliser ZColorPalette.defaultStudy pour un jeu de clés const.
