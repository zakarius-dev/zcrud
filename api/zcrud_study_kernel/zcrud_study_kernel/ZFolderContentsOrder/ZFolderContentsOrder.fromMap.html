Reconstruit défensivement depuis une map persistée (invariant AD-10) — ne lève jamais, pas même sur une map vide.

Recopie le champ codegen (folderId, via le décodeur généré — folder_id absent/non-String → '') puis câble les canaux hors-codegen : section_orders (décodage à deux niveaux + immuabilité profonde via _decodeSectionOrders), extension (repli null) et extra (clés non réservées).

Ne délègue jamais nuement au décodeur généré (l'entité est ZExtensible) — elle peuple extra explicitement, ainsi que le canal section_orders.

Implementation

factory ZFolderContentsOrder.fromMap(
  Map<String, dynamic> map, {
  ZFolderContentsOrderExtensionParser? extensionParser,
}) {
  final base = _$ZFolderContentsOrderFromMap(map);
  return ZFolderContentsOrder(
    folderId: base.folderId,
    // Canal hors-codegen — décodage défensif à deux niveaux.
    sectionOrders: _decodeSectionOrders(map[kSectionOrdersKey]),
    extension: _decodeExtension(map['extension'], extensionParser),
    extra: _extraFrom(map),
  );
}
