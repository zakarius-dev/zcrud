day est-il un jour civil lisible (yyyy-MM-dd, date réellement existante) ?

Défensif (invariant AD-10) : rend false — jamais de throw — pour null, une chaîne vide, un format libre ('28/03/2026'), ou une date impossible ('2026-02-31', '2026-13-01'). C'est le critère unique de lisibilité consommé par ZStudyStreak.fromMap et par zAdvanceStreak : aucune date ne peut tomber entre les deux.

Implementation

bool zIsCivilDay(String? day) => zParseCivilDayNumber(day) != null;
