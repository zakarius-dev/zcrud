extraKey

extraKey property

String extraKey
final

Clé d'ZSmartNote.extra tenue en doublon du champ typé, et qui fait FOI à la relecture chez l'hôte.

Elle DOIT être une clé non réservée (ni un champ de schéma, ni extension, ni content, ni une clé de sync ZSyncMeta) : ZSmartNote dépouille les clés réservées de extra sur toutes ses voies d'écriture. Une clé réservée rendrait le canal INERTE — le cas est signalé par un assert en debug (applyTo), jamais par un throw en release (AD-10).
