ZBreakpointValue

ZBreakpointValue<T> class

Valeur de type T déclinée par breakpoint avec cascade mobile-first.

Palier de base xs requis; sm/md/lg/xl optionnels — un palier non fourni hérite du palier renseigné le plus proche en dessous (cascade xl→lg→md→sm→xs). @immutable, ==/hashCode par valeur (patron ZResponsiveSpan du cœur, sans le clamp [1,12]).

Annotations
