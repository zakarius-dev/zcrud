Crée une grille adaptative VIRTUALISÉE.

Construit à la demande (itemBuilder n'est appelé que pour les items du viewport, ≪ itemCount) et scrolle d'elle-même: ni shrinkWrap, ni NeverScrollableScrollPhysics — c'est la surface scrollable.

Réutilise à l'identique computeCrossAxisCount, la garde vide (itemCount <= 0 → SizedBox.shrink()) et les replis AD-10 du ctor historique: « jamais une grille réécrite » reste vrai (même widget, même primitive de colonnes).

itemCount <= 0 ⇒ SizedBox.shrink() (AD-10, jamais de throw).
