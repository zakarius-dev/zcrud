ZContentHubSection class

Un groupe titré d'entrées du hub.

Un rendu antérieur ne titrait pas les familles et rendait une liste plate. C'est un argument d'échelle, pas de goût : le composant dont la raison d'être est d'accueillir de nouveaux types doit rester lisible quand on en accueille.
