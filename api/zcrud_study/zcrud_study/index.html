zcrud_study

zcrud_study library

Barrel d'API publique de zcrud_study.

Paquet de présentation de l'orchestration « study tools » : hub de contenu, sections d'outils composables, génération de flashcards par IA, partage et modération, session de révision assemblée, examens et rappels, cartes par défaut pour chaque type de contenu. API publique : ce barrel ; implémentation sous lib/src/. zcrud_study dépend de zcrud_core et zcrud_study_kernel, jamais l'inverse (invariant AD-1).
