ZStudySessionLabels class

Libellés injectés de l'écran de session (FR-26).

Un champ nul retombe sur label(context, clé, fallback:) — donc sur la résolution l10n de l'hôte (ZcrudScope.labels, puis le delegate, puis la table en), et seulement en tout dernier recours sur le repli français. Aucun libellé n'est donc figé dans l'arbre.
