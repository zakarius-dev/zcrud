ZMenuEntry toMenuEntry()

Projection vers l'entrée NEUTRE de zcrud_menu.

Publique à dessein : une présentation injectée (ZItemActionsMenuBuilder) peut ainsi rendre chaque action avec ZMenuEntryTile — cible ≥ 48 dp, Semantics NON dupliquées, directionnalité — au lieu de les réécrire.

ZMenuEntry.isDestructive est dérivé de kind : c'est une donnée, pas un style (FR-26 — le socle ne lui associe aucune couleur).

Implementation

ZMenuEntry toMenuEntry() => ZMenuEntry(
      id: entryId,
      label: label,
      icon: icon,
      onSelected: onSelected,
      disabledReason: disabledReason,
      permitted: permitted,
      isDestructive: kind == ZItemActionKind.delete,
    );
