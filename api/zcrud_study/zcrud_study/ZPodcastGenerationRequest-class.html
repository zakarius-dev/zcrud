ZPodcastGenerationRequest

ZPodcastGenerationRequest class

Requête immuable de génération de podcast (value-object, ==/hashCode par valeur — égalité profonde de extra).

Ne porte que du contenu source neutre, adressable par contenu : aucun prompt, aucun endpoint, aucune clé, aucun paramètre de transport (invariant AD-12). Le sourceHash est une empreinte opaque fournie par l'appelant — le domaine ne la calcule pas. Le sourceKind est un enum kernel fermé.
