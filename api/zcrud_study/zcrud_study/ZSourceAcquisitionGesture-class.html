ZSourceAcquisitionGesture

ZSourceAcquisitionGesture class

Geste d'ACQUISITION de source branché par l'hôte — « uploader », « scanner »… Libellé et icône INJECTÉS, jamais en dur.

Le socle ne connaît ni le sélecteur de fichiers ni le scanner : il offre le créneau et reçoit ce que le geste produit — une ZGenerationSourceOption utilisable dans la même session de feuille (ajoutée aux sources du contexte et pré-sélectionnée), sans rompre le flux : le paramétrage déjà saisi (contenu, nombre, types, instructions, modelId) survit à l'acquisition.

Conserver le fichier acquis dans le dossier ou le laisser éphémère est une décision de PRODUIT prise par l'hôte DANS acquire — le contrat ne l'impose pas (AD-4).
