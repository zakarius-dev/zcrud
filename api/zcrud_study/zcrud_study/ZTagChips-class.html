ZTagChips

ZTagChips class

Rangée de puces de tags (affichage seul — StatelessWidget).

La couleur de fond de chaque puce FILE la palette INJECTÉE à travers remapColorKey puis le résolveur du cœur (zResolveColorKeyOrSlot) — jamais une couleur codée en dur ni la palette ignorée (AC1). Le compteur d'usages est DÉRIVÉ au rendu (AC4).
