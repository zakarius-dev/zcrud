initialSelectedSubfolderId property

String? initialSelectedSubfolderId
final

Sélection initiale (null = item racine « Tous les sous-dossiers »).

IGNORÉ quand nav.selectionController est fourni : le contrôleur est alors le propriétaire de l'état, donc de son amorce (initialValue). Recopier cette valeur dedans au montage ferait écrire le socle dans l'état de l'hôte — et écraserait une sélection que l'hôte a pu restaurer d'un lien profond. Même arbitrage que ZStudyToolsSectionSpec.expandController vs initiallyExpanded.
