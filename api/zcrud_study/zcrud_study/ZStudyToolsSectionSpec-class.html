ZStudyToolsSectionSpec

ZStudyToolsSectionSpec class

Descripteur immuable d'une section de la page « study tools ».

Une instance par section (rail de flashcards, grille de documents, grille de notes, grille de cartes mentales…). Chaque section est rendue par ZSectionedStudyLayout dans son propre sous-arbre isolé (frontière de rebuild — invariant AD-2).
