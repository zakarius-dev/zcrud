ZDailyTasksView

ZDailyTasksView class

Corps composable de la vue des tâches du jour.

Voir la dartdoc de bibliothèque pour le dispatch ouvert, l'horloge injectée et les invariants. Ce type est un StatelessWidget par construction : la sélection est détenue par l'hôte (AD-2 — un seul propriétaire d'état).
