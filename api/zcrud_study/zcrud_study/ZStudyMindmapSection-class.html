ZStudyMindmapSection

ZStudyMindmapSection class

Section « carte mentale » composée par folderId dans la page study-tools.

StatefulWidget uniquement pour (a) le cycle de vie du ZMindmapOutlineController POSSÉDÉ (créé initState ssi non injecté, disposé dispose ssi possédé) et (b) le ValueNotifier<ZStudyMindmapMode> local de la bascule lecture ⇄ édition. JAMAIS pour l'état de la carte (qui vit dans le controller / la donnée immuable passée en entrée).
