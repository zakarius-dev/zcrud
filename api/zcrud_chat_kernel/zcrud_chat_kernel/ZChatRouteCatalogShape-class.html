ZChatRouteCatalogShape

ZChatRouteCatalogShape class

Forme d'un catalogue reçu : une donnée qui dit comment traduire les clés d'un backend vers le schéma canonique du routeur.

Construire une forme, c'est nommer des clés — jamais écrire du code d'adaptation. Les presets (canonical, lex) et la fabrique suffixPairs couvrent les dispositions connues ; une disposition inédite se déclare avec le constructeur.
