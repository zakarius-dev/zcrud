Rend une requête identique, sauf les champs fournis.

Un paramètre omis conserve la valeur courante ; un champ nullable se retire en passant null explicitement (copyWith(style: null)). C'est ce qui permet à un ajusteur d'hôte de poser subjectRequired ou style sans reconstruire toute la requête.
