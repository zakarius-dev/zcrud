ZChatSseLine

ZChatSseLine class

Une ligne du flux SSE, déjà décodée et classée.

Value object immuable. sequenceId est la dernière valeur de id: vue jusqu'à cette ligne incluse (null tant qu'aucune n'a été émise, ou après un id: vide) — c'est la position que l'appelant renvoie à ZChatRequestToken.resumeFrom pour reprendre après coupure. eventName est le dernier event: du bloc courant (réinitialisé à chaque ligne vide, conformément au protocole).
