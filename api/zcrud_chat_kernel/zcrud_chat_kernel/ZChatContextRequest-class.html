ZChatContextRequest

ZChatContextRequest class

Portée pour laquelle un contexte est demandé — immuable.

Tous les champs sont optionnels : un hôte n'a pas toujours de conversation (première question), pas toujours de dossier (chat libre). scope est l'échappatoire opaque par laquelle l'hôte passe ses propres identités (dossier, matière, niveau, documents) sans que le socle ait à les connaître — le vocabulaire d'étude d'une application (folder, cycle, niveau) n'a pas à devenir celui des autres.
