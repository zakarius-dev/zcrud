ZChatToolCatalog

ZChatToolCatalog class

Le catalogue déclaré : des sections, des entrées, et rien d'autre.

Immuable : chaque opération d'écriture rend un nouveau catalogue. C'est ce qui rend l'exclusion mutuelle et la remise à zéro vérifiables — un état dérivé ne peut pas se désynchroniser d'un état muté ailleurs.

Constructors

ZChatToolCatalog({Iterable<ZChatToolSection> sections = const <ZChatToolSection>[], Iterable<ZChatToolEntry> entries = const <ZChatToolEntry>[]})
Construit un catalogue. Les entrées et les sections sont dédupliquées par clé — la première déclaration gagne, les suivantes sont écartées.
