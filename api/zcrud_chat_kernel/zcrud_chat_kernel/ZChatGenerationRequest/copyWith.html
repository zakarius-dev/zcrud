Copie à sentinelle : un argument omis conserve la valeur courante, null explicite remet un champ nullable à null (copyWith(modelId: null) retire le modèle). C'est l'unique voie de recopie de la requête : withSettings, withCorpusScope et la projection d'une résolution de route passent tous par elle.

Les invariants du constructeur s'appliquent à la copie comme à l'original : context réordonné, capabilities canonicalisées (la clé réservée web_search est hissée dans webSearch si celui-ci est null), extra expurgé des clés réservées. Une copie sans argument est égale à l'original.
