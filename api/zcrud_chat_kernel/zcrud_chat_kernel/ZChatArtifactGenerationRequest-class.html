ZChatArtifactGenerationRequest

ZChatArtifactGenerationRequest class

Requête immuable de génération d'un artefact.

Ne porte aucune mécanique de transport ni de prompt (invariant AD-12) : le style est une donnée ouverte, les instructions une consigne neutre.
