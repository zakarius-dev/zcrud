ZChatGenerationRequest

ZChatGenerationRequest class

Requête immuable de génération (value object, ==/hashCode par valeur) — partagée par le port one-shot et le port de streaming.

Une seule requête pour les deux ports : la différence entre « je veux la réponse » et « je veux la réponse au fil de l'eau » est un choix de transport, pas une différence de demande. Trois signatures distinctes portant chacune une copie dérivée des mêmes paramètres serait le coût de l'inverse.

Ne porte aucune mécanique de transport ni de prompt (invariant AD-12) : ni endpoint, ni clé, ni instruction système assemblée.
