ZChatGenerationStyle class

Style de génération, immuable et ouvert.

kind est un discriminant technique (jamais un libellé d'affichage : le libellé et l'icône appartiennent à l'hôte — invariant AD-13). params porte les paramètres propres au style de l'hôte, verbatim ou reconstruits par le codec que l'hôte a enregistré dans un ZTypeRegistry.
