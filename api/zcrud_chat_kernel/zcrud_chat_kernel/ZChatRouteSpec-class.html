ZChatRouteSpec class

Déclaration d'une route pour une clé de tâche.

Constructors

ZChatRouteSpec({required String taskKey, String? routeName, ZChatModelRef? model, List<ZChatModelRef> fallbacks = const <ZChatModelRef>[], ZChatComputeEffort? computeEffort, Map<String, dynamic> params = const <String, dynamic>{}, List<String> requiredAccessTokens = const <String>[], String? handlerId})
