ZChatCapabilityAudit

ZChatCapabilityAudit class

Résultat de la confrontation « capacités EXPRIMÉES ↔ capacités HONORÉES » — immuable, produit par ZChatGenerationSettings.auditCapabilities.

Une clé exprimée est une clé pour laquelle la demande porte une valeur (true ou false : demander « web coupé » exige d'être honoré autant que « web actif » — un port qui ne sait pas couper le web ne doit pas laisser croire qu'il l'a coupé).
