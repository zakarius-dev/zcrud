ZChatCorpusSelector

ZChatCorpusSelector class

Un sélecteur de portée : une famille, et facultativement les seules clés de corpus admises dans cette famille.

Les deux niveaux sont ceux de lex, rendus génériques :

Niveau Champ null/vide signifie
1 — famille sourceType toute famille
2 — corpus corpusKeys tout corpus de la famille

Un sélecteur totalement vide (sourceType == null, corpusKeys vide) n'admet donc aucune restriction : il vaut « tout ». C'est voulu — la portée par défaut d'un hôte qui n'a rien réglé ne doit rien interdire.
