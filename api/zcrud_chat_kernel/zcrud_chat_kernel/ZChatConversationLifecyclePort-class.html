ZChatConversationLifecyclePort

ZChatConversationLifecyclePort class abstract interface

Port de cycle de vie — retrait et élagage, jamais purge (invariant AD-9).

Le contrat de ce port est SOFT dans les trois membres. Une implémentation qui supprimerait physiquement le document le viole, même si elle compile : is_deleted/updated_at de ZSyncMeta sont l'unique mécanisme de retrait du dépôt, et une purge rend le merge Last-Write-Wins incapable de propager le retrait aux autres appareils (le distant réhydrate ce que le local a effacé).
