ZChatArtifactVerb

ZChatArtifactVerb class

Un verbe offert sur un artefact, déclaré par l'hôte.

La key est un vocabulaire ouvert (invariant AD-4) : les constantes kZChatArtifactVerb* sont des conventions, pas une énumération fermée. Un verbe destructive exige une confirmation avant son exécution — c'est ZChatArtifactDeclaration.requiresConfirmation qui le dit, et aucune présentation ne peut le contourner.
