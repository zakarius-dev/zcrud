ZChatCustomToolState

ZChatCustomToolState class

Nature d'hôte — l'échappatoire du vocabulaire scellé (invariant AD-4).

Un hôte déclare sa propre nature en instanciant ce variant : il fournit le discriminant, l'activité et le jeton d'état, et transporte son payload dans data. Le socle ne sait pas la rendre — c'est au rendu d'hôte de le faire — mais elle traverse le catalogue, compte dans les agrégats et se sérialise.
