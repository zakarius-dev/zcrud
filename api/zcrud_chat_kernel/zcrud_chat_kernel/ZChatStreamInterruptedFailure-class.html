ZChatStreamInterruptedFailure

ZChatStreamInterruptedFailure class

Le flux a été interrompu avant son événement terminal.

Porte requestId — l'identité du ZChatRequestToken de la requête coupée, pour que l'hôte sache laquelle de ses requêtes concurrentes s'est arrêtée, plutôt que de devoir supposer qu'il s'agit de « la dernière lancée ». cancelledByUser sépare l'arrêt voulu (aucune erreur à afficher) de la coupure subie (réseau, timeout) : les aplatir forcerait l'hôte à afficher une erreur sur un geste volontaire. eventsReceived dit si un contenu partiel a été rendu et mérite d'être conservé.
