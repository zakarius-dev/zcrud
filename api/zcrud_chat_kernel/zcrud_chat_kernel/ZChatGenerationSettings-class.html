ZChatGenerationSettings

ZChatGenerationSettings class

Réglages de génération transportables — immuable, ==/hashCode par valeur.

Tout est nullable, et null signifie « l'hôte décide » — jamais un défaut inventé par le socle. Un porteur entièrement nul (isEmpty) laisse le comportement strictement inchangé.
