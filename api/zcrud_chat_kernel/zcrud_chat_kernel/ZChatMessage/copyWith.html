Copie à sentinelle : un argument omis conserve la valeur courante, un null explicite la remet à null, étendu à tous les champs nullables — une sentinelle partielle ne couvrant qu'une partie des champs laisserait les autres impossibles à remettre à null.

extra est sanitisé eager ici : une voie d'écriture qui ne filtrerait pas laisserait la garde d'invariant rouvrable.
