ZChatContextFragment class

Un fragment de contexte d'étude, immuable et neutre.

kind est un discriminant technique ouvert ('userPresentation', 'folder', 'level', 'documentSummary'…) : aucun catalogue fermé, aucun libellé d'affichage. text est le contenu injectable, jamais un prompt système complet.
