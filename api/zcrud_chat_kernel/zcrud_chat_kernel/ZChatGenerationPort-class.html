ZChatGenerationPort

ZChatGenerationPort class abstract interface

Port one-shot de génération de texte, paramétré par style.

Rend une liste de ZContentBlock — la famille ouverte que ce package porte déjà — et non une String : c'est le seam large. Une réponse purement textuelle est un [ZTextBlock(...)] ; une réponse structurée (tableau, chronologie, diagramme, bloc d'hôte enregistré) n'exige aucun changement d'API. Le socle n'a pas à trancher aujourd'hui ce que le fournisseur d'un hôte saura produire demain.

Invariant AD-5 : Either<ZFailure, ·>. Invariant AD-10 : aucune exception ne s'échappe — les échecs typés sont ceux de z_chat_ai_failure.dart (dont ZQuotaExceededFailure, type existant du cœur).
