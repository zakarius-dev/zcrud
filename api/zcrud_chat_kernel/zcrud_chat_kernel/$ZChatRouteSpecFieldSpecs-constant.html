$ZChatRouteSpecFieldSpecs top-level constant

List<ZFieldSpec> const $ZChatRouteSpecFieldSpecs

Sous-schéma d'édition d'une route — items de la sous-liste routes d'un routeur. Aucun libellé : les textes viennent de l'hôte.

Les replis s'éditent en sous-liste (subItems) emboîtée dans l'item de route, chaque repli étant décrit par $ZChatModelRefFieldSpecs ; le résumé d'un repli montre son fournisseur et son modèle. Les params ne sont pas un champ : ils sont conservés tels quels par le sous-formulaire.

Implementation
