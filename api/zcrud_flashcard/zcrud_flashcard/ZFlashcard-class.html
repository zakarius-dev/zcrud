ZFlashcard

ZFlashcard class

Flashcard canonique immuable (données et copyWith ; les invariants métier vivent au repository).

Implémente ZSessionCandidate : ZFlashcard est un candidat filtrable par un sélecteur de session via ses clés neutres folderId/subFolderId/ tagIds et typeKey (le name du type, exposé comme une clé opaque String) — le noyau d'étude reste ainsi ignorant de ZFlashcardType.
