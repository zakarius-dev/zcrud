ZSrsConfig

ZSrsConfig class

Paramètres immuables de l'algorithme de répétition espacée (SuperMemo-2 par défaut). Toutes les constantes de ZSm2Scheduler sont lues depuis une instance de cette classe — aucune constante SM-2 n'est codée en dur dans l'algorithme.

Constructors

ZSrsConfig({double minEaseFactor = 1.3, double maxEaseFactor = 2.5, double defaultEaseFactor = kDefaultEaseFactor, double defaultIntervalModifier = 1.0, double overdueBonusFactor = 0.0, int passThreshold = 3, int minQuality = 0, int maxQuality = 5})
Construit une configuration SRS avec les défauts canoniques. Tout paramètre peut être surchargé pour ajuster la courbe.
const
