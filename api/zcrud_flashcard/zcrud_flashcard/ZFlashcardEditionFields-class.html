ZFlashcardEditionFields

ZFlashcardEditionFields class abstract final

Fabriques de ZFieldSpec d'un formulaire d'édition flashcard standard. Les specs des trois champs flashcard-spécifiques (type/QCM/vrai-faux) portent une ZFlashcardFieldConfig sur EditionFieldType.custom ; les champs texte/tags utilisent les familles du cœur.
