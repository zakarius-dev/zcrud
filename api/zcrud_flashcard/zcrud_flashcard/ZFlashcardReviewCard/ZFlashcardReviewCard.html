Construit la carte de révision de card.

  • revealTransition : transition souhaitée (Reduce Motion prime) ;
  • contentBuilder : slot de rendu de contenu opt-in (null ⇒ texte brut) ;
  • questionTypeBadgeBuilder : badge de type déjà localisé par l'hôte ;
  • instructionBanner : consigne déjà localisée par l'hôte ;
  • transitionDuration : override explicite de durée. La priorité est l'override, puis ZcrudTheme.flipDuration, puis 250 ms ;
  • onRevealChanged : notification sortante de la révélation (la carte ne cède jamais la propriété de son état — invariant AD-2) ;
  • onEdit/onDelete/onSource : actions injectées — null ⇒ action absente, exactement comme ZFlashcard.isReadOnly : une seule règle.
