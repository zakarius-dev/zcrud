ZFlashcardAnswerEvaluationRequest

ZFlashcardAnswerEvaluationRequest class

Requête immuable d'évaluation d'une réponse rédigée (value-object, ==/hashCode par valeur).

Ne porte que du contenu neutre : aucun prompt, aucun point de terminaison, aucune clé (invariant AD-12). N'est jamais construite pour un QCM ou un vrai/faux.
