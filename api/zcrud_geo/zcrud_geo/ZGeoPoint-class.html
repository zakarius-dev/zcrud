ZGeoPoint

ZGeoPoint class

Point géographique neutre : latitude/longitude + libellé/adresse optionnels.

Available extensions
  • ZGeoPointGeoJson

Constructors

ZGeoPoint({required double lat, required double lng, String? label, String? address, ZGeoShapeStyle? style})
Construit un point aux lat/lng (degrés décimaux) et métadonnées optionnelles. Aucune validation dure (pas d'assert) : les bornes sont vérifiées au parse défensif (fromMapSafe) — un point construit programmatiquement reste sous la responsabilité de l'appelant.
const

Alias défensif de fromMapSafe (nullable) — cohérence de nommage toMap/fromMap. Ne throw jamais (AD-10).
fromMapSafe(Object? raw) → ZGeoPoint?
Parse défensif : retourne null sans jamais throw si raw n'est pas une Map (ou une String JSON encodée en contenant une), si lat/lng sont absents/non numériques/non finis, ou hors-bornes. label/address non-String → ignorés (dégradés à null).
