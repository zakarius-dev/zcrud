ZOsmMapAdapter

ZOsmMapAdapter class

Adaptateur carte OSM (sans clé API). Possède un MapController natif disposé via dispose.

Opte pour les capacités ZMapCameraCapable (caméra pilotée via MapController.move/fitCamera) et ZMapGesturesCapable. flutter_map n'a aucun marqueur draggable natif : le drag est implémenté ici par geste custom (_ZOsmDraggableMarker) — conversion écran↔coordonnées via MapCamera.of(context) (latLngToScreenOffset/screenOffsetToLatLng), position appliquée en fin de drag (contrat *DragEnd).
