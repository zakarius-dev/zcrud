Construit la vue personnalisée typée : view reçoit le résolveur ZListRow → T? de la liste.

Le résolveur ne lève jamais (AD-10) : une entité d'un autre type que T est résolue null, comme une ligne inconnue.

Implementation

static ZListCustomLayout forEntity<T extends ZEntity>(
  ZEntityListViewBuilder<T> view,
) =>
    ZListCustomLayout(
      entityView: (context, request, entityFor) => view(
        context,
        request,
        (row) {
          final entity = entityFor(row);
          return entity is T ? entity : null;
        },
      ),
    );
