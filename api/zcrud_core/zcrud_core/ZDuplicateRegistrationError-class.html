ZDuplicateRegistrationError

ZDuplicateRegistrationError class

Levée quand un kind déjà enregistré est ré-enregistré sur le même registre (collision).

Sous-type de Error : on throw plutôt qu'un remplacement silencieux « last-wins ». Un last-wins masquerait une double génération (deux part codegen enregistrant le même modèle) ou un ordre de bootstrap fautif — exactement le genre de bug qu'AD-3 veut rendre explicite. Un besoin d'override légitime (hot-reload/tests) sera ajouté additivement (paramètre override: true), sans changer ce défaut.
