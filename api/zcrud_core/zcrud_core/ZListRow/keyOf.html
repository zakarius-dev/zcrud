Clé de ligne standard d'une entity : son id s'il est attribué, sinon une clé éphémère dérivée de l'identité mémoire de l'instance.

C'est la convention publique de tout l'assemblage zcrud (ZCrudScreen la suit) : un hôte qui doit reconstruire l'index ZListRow.id → entité consommé par DynamicList.entityFor appelle cette fonction au lieu de deviner la formule. La clé d'une entité éphémère est stable tant que l'instance vit (mêmes lignes sélectionnées d'un rebuild à l'autre) ; dès que la persistance attribue un id, c'est lui qui devient la clé.

Implementation

static String keyOf(ZEntity entity) =>
    entity.id ?? ephemeralKey(identityHashCode(entity));
