ZSyncMeta

ZSyncMeta class

Value object immuable portant les métadonnées de synchronisation standardisées hors-entité (AD-9) : la clé Last-Write-Wins updatedAt et le drapeau de soft-delete isDeleted.

Séparation stricte (canonique §2.2) : aucun champ métier de l'entité ne vit ici. Persistance en clés snake_case updated_at / is_deleted (convention canonique §5), dates en ISO-8601 (AD-5 : backend-agnostique, jamais de Timestamp).
