EditionFamily

EditionFamily enum

Famille de rendu d'un champ d'édition.

Les six premières valeurs sont les familles de base servies par un widget dédié ; hidden rend un widget zéro-taille ; unsupported est le repli contrôlé (registre / hors-parité) — jamais une exception.
