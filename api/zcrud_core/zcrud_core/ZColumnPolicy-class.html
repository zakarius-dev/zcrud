ZColumnPolicy

ZColumnPolicy class

Politique de colonnes additive (AD-4) : permet à l'appelant de forcer l'inclusion/exclusion d'un champ par name, de régler une colonne précise (overrides) et de demander la colonne de numéro d'ordre (ordinal), SANS modifier ZFieldSpec ni les annotations @ZcrudField (gelées). Point d'extension const-compatible.

Précédence (cf. deriveColumns) : forceExclude l'emporte sur forceInclude (l'exclusion explicite gagne en cas de conflit), qui l'emporte sur la visibilité par défaut fondée sur le type/isId.
