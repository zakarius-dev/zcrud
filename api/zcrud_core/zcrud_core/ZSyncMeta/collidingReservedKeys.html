Clés RÉSERVÉES qu'un corps métier porterait à tort.

La collision est probable : updatedAt est l'un des noms les plus répandus des modèles applicatifs, et un hôte peut légitimement porter un « dernière modification par l'utilisateur » — qui n'est PAS l'estampille Last-Write-Wins. Le contrat de clé réservée n'est pas remis en cause ; ce qui l'est, c'est que l'écrasement soit muet.

Exposé pour qu'un hôte puisse vérifier avant d'écrire plutôt que de découvrir la perte en production :

final collided = ZSyncMeta.collidingReservedKeys(monEntite.toMap());
if (collided.isNotEmpty) { /* renommer, ou porter dans `extra` */ }

En debug, stripReserved journalise déjà la collision ; cette fonction permet de la traiter programmatiquement, y compris en release.
