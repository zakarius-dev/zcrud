ZListRenderRequest

ZListRenderRequest class

Requête de rendu neutre et immuable consommée par ZListRenderer.

Porte les columns dérivées (ZListColumn : en-tête non résolu, largeur, format pur — cf. ZListRenderRequest.fromSchema) et les rows. Le backend consomme le format neutre partagé (col.format(row.cells[col.name])) sans re-dériver ni dupliquer de logique de format. Aucun état loading/empty/noResults/error (dans DynamicList/ZListViewState), aucun tri/filtre.

Immuable (const + champs final) ; égalité de valeur profonde (listes et cellules comparées élément par élément).
