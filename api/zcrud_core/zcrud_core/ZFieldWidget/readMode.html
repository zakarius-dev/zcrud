readMode

readMode property

bool? readMode
final

Mode de présentation de ce champ — signal DISTINCT de ZFieldSpec.readOnly (qui dit « ce champ-ci n'est pas modifiable », jamais comment le présenter).

true et famille « fiche-able » (zReadModeCardable) ⇒ le champ est rendu en fiche de consultation (ZReadOnlyFieldCard) : libellé au-dessus de la valeur, ni bordure, ni libellé flottant, ni ornement. Les familles non fiche-ables (sous-liste, item dynamique, signature, fichier…) conservent leur rendu readOnly existant.

null (défaut) ⇒ le mode de la surface environnante (ZReadModeScope, posé par DynamicEdition/ZStepperEdition d'après leur readOnly) ; false hors de toute surface. Le passer explicitement prime sur cette surface, dans les deux sens : false force la saisie au milieu d'une fiche, true force la fiche au milieu d'un formulaire.

Le mode est arrêté au montage du champ (une fiche n'alloue ni contrôleur de texte ni clavier) : le faire changer suppose de remonter le champ, ce que fait l'écran assemblé en keyant la place sur le mode.
