Décode map en T via le codec du kind résolu depuis T (variante typée de decode pour un appelant générique sur T).

Retourne directement un T (cast sûr : le codec enregistré sous ce kind a été construit avec un fromMap produisant un T).

Contrat d'erreur — jamais un silence :

  • T non enregistré → throw StateError actionnable ;
  • T enregistré sous plusieurs kind → throw StateError nommant le type et les kind (contrat de kindOf) : utilisez decode avec le kind explicite.

Le contexte (ZDecodeContext) est threadé exactement comme par decode.

Implementation

T decodeOf<T extends Object>(Map<String, dynamic> map) =>
    decode(_kindOfStrict<T>('decodeOf'), map) as T;
