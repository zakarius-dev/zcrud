Rend value pour l'affichage.

mode distingue une date seule d'une date+heure (ZDateMode.time n'est jamais transmis — cf. dartdoc de bibliothèque). localeTag est la BCP-47 de la locale ambiante (fr-FR, en), ou null si l'arbre n'en porte pas — l'impl choisit alors sa locale par défaut.

Retourner null (ou une chaîne vide) ⇒ repli du socle (chaîne brute).
