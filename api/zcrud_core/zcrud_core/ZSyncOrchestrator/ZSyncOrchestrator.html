Construit l'orchestrateur.

  • debounce : fenêtre de coalescence trailing (défaut kZSyncDefaultDebounce = 400 ms). Plusieurs déclencheurs dans la fenêtre réarment le timer et coalescent en un seul cycle.
  • timerFactory : couture de fabrique de timer (défaut = Timer réel de dart:async). En test, injecter une fabrique contrôlable pour piloter le débounce sans horloge murale.
  • isConnected : couture de connectivité optionnelle (défaut null → jamais court-circuité). Point d'injection de la vraie source réseau de l'app. Quand présente et false, un cycle est sauté proprement.
  • enabled : gate d'activation (défaut true). false → aucun déclencheur ne planifie, aucun cycle ne s'exécute.
  • logger : journal neutre (défaut no-op).
