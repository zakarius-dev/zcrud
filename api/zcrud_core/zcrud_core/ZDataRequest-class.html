ZDataRequest

ZDataRequest class

Value object neutre et immuable décrivant une requête de lecture.

Porte les filters, le tri sorts, la search plein-texte et la pagination curseur (limit + startAfter). Un ZDataRequest() par défaut (aucun filtre/tri/curseur, tout null) représente « tout, non paginé » et est valide.

Immuable (const + champs final) ; égalité de valeur profonde (listes comparées élément par élément). copyWith utilise une sentinelle permettant de remettre à null search/limit/startAfter.
