viewAccess

viewAccess property

ZTrashViewAccessCondition? viewAccess
final

Condition applicative optionnelle d'accès à la vue corbeille.

null conserve le critère historique, juste pour la plupart des écrans : l'ACL doit autoriser à restaurer ou à purger. Déclarez cette condition uniquement pour une règle d'ACL que ce critère ne peut pas exprimer (par exemple une règle de rôle propre à une collection). Si elle est fournie, elle remplace ce critère de visibilité, sans jamais ouvrir les gestes de restauration ou de purge, qui restent chacun gouvernés par l'ACL.

L'écran traite toute exception comme un refus. Après cette condition, visibleWhenEmpty reste appliqué : une corbeille vide masquée le reste.
