activeIndexNotifier

activeIndexNotifier property

ValueNotifier<int>? activeIndexNotifier
final

Notifieur possédé par l'appelant (create/dispose côté hôte), tenu synchronisé par le widget avec l'index de l'onglet actif : positionné à l'index initial effectif dès le montage, puis à chaque changement d'onglet (tap ou swipe), avant l'appel de onTabChanged.

Lu comme ValueListenable<int>, il évite à l'hôte de dupliquer un _activeIndex maintenu à la main : un geste de création lit par exemple tabs[notifier.value].defaultItemBuilder / tabs[notifier.value].canCreate pour hériter du contexte (et de l'autorisation) du segment courant.

Le flux est à sens unique (widget → hôte) : écrire dans ce notifieur côté hôte ne change pas l'onglet actif (la valeur serait écrasée à la prochaine synchronisation) — l'onglet initial se pilote par initialIndex, le changement par le geste de l'usager.

null (défaut) = aucun suivi, comportement antérieur inchangé.
