ZEditionStep

ZEditionStep class

Descripteur présentation d'une étape : un titre + le sous-ensemble de noms de champs du catalogue qu'elle regroupe (aligné sur ZEditionSection — titre + noms, PAS une nouvelle donnée de formulaire). Additif, const.

icon et subtitle portent les métadonnées d'affichage par étape ; nestedSteps/nestedConfig portent un sous-stepper imbriqué rendu sur le MÊME controller. Tous ces paramètres sont additifs : les sites existants sans eux compilent inchangés.
