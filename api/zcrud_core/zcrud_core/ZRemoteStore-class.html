ZRemoteStore

ZRemoteStore<T extends ZEntity> class abstract

Contrat abstrait (port) du store distant d'un agrégat T — la moitié « best-effort » du patron offline-first (AD-9).

Fire-and-forget / best-effort (AD-9) : le distant n'est jamais la source de vérité. Un échec distant ne doit pas invalider l'état local autoritaire (ZLocalStore). Ce port se borne à exposer les primitives pousser / tirer un agrégat ; la composition local↔distant, le merge Last-Write-Wins sur updatedAt, la cascade bornée et le débounce (ZSyncOrchestrator) ne vivent pas ici (frontière volontaire — aucune orchestration dans ce port).

Backend-agnostique (AD-5) : aucune signature n'expose de type cloud_firestore. L'adaptateur concret (FirestoreZRemoteStore, zcrud_firestore) délègue au repository Firestore ; les dates transitent en ISO-8601 (jamais Timestamp).

Contrat de résultat (AD-11) : ZResult<...> / ZResult<Unit> ; une erreur d'accès distant est un ZServerFailure. Les flux sont des Stream<List<T>> NUS.
