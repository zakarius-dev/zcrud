ZDependencyResolver

ZDependencyResolver class abstract

Résolveur de dépendances abstrait fourni par l'app/binding.

L'implémentation par défaut (throwing) lève ZScopeError sur tout resolve : rien n'est résolu magiquement tant qu'un binding/scope n'a pas explicitement fourni la dépendance. Le seam de cycle de vie du ZFormController (création/scoping/dispose) est, lui aussi, résolu par ce canal côté binding ; le défaut zéro-config est le « cycle local possédé par l'hôte » (l'hôte crée et dispose() son contrôleur).
