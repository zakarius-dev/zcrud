Fabrique catégorie (cas courant) : les filters de catégorie sont passés à buildList, qui les branche typiquement en baseFilters sur le ZListController/ZSubListScreen de l'onglet — la catégorie ne peut alors JAMAIS être écrasée par une recherche/un filtre utilisateur.
