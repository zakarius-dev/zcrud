ZExtension

ZExtension class abstract

Contrat abstrait d'une extension type additive versionnée portée par une entité canonique (via ZExtensible).

Chaque sous-classe concrète (en satellite) :

  1. porte un formatVersion propre, indépendant du schéma du parent (évolution additive — AD-10) ;
  2. sérialise via toJson ;
  3. expose par convention un static X? fromJsonSafe(json) bâti sur guard, renvoyant null si json est null, corrompu, ou de formatVersion non gérée — jamais de throw (AD-10).
