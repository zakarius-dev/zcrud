ZStepperConfig

ZStepperConfig class

Configuration const & immuable de ZStepperEdition.

Tous les défauts reproduisent le comportement de référence (indicateur top/horizontal/numbered « k/N » + titre, gate strict validateOnNext). Les overrides couleur sont nullables (défaut null) → dérivés du ColorScheme par le rendu (invariants AD-6/FR-26). Les mesures (indicatorSize, stepSpacing) sont des tokens de config surchargeables par l'app.
