hasExplicitVisibleFields property

bool hasExplicitVisibleFields
final

true ssi l'hôte a fourni visibleFields à la construction. C'est la SEULE information qui distingue un ensemble structurel voulu par l'hôte d'un amorçage de repli dérivé des clés de initialValues — le constructeur la perdait, ce qui rendait l'ordre d'affichage tributaire de l'ordre de la Map de persistance, silencieusement.

DynamicEdition la lit pour décider s'il doit AMORCER visibleFields sur l'ordre canonique de son schéma (fields) : false ⇒ le schéma fait foi ; true ⇒ l'hôte est autoritaire, rien n'est réamorcé.

Fixée une fois pour toutes : un setVisibleFields ultérieur (par l'hôte ou par le formulaire lui-même) ne la modifie PAS — sinon la première écriture du formulaire s'auto-déclarerait « explicite » et neutraliserait tout réamorçage sur changement de schéma.
