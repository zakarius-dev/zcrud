ZSelectChoiceContext

ZSelectChoiceContext class

Contexte neutre d'une option en cours de construction par un ZSelectChoiceBuilder.

Porte ce qu'un builder d'option a besoin de lire (choice, selected, enabled) et l'unique action qu'il a le droit d'exercer (select).

select est indispensable : un builder de rendu d'option a presque toujours besoin de déclencher lui-même la sélection depuis son propre contrôle — un builder strictement lecture-seule serait une capacité en trompe-l'œil.
