Construit le codec pour kind à partir de fromMap/toMap.

fromMapWithContext/toMapWithContext (additifs, null par défaut) portent les variantes conscientes du contexte : émises par le générateur pour toute entité dont la factory de domaine accepte un extensionParser et/ou un sourceRegistry (AD-4).
