DynamicList

DynamicList<T extends ZEntity> class

Widget public affichant une liste, piloté par un ZListViewState et une variante de vue ZListLayout.

  • Les états loading/empty/noResults/error sont rendus par CE wrapper (accessibles, Semantics/liveRegion) SANS invoquer le renderer.
  • En état ready, les colonnes sont dérivées (columnPolicy appliquée) puis le rendu dispatch sur layout :
    • dataGrid (défaut) → délègue au renderer injecté (paramètre) ou au seam ZcrudScope.listRenderer ; si AUCUN → ZScopeError actionnable orientée zcrud_list (chemin dataGrid uniquement) ;
    • builder/custom → rendu dans le cœur, aucun renderer requis.
  • En présence d'une selection et/ou de rowActions, un ZListInteraction neutre est construit (sélection keyée par id, actions filtrées par ZcrudScope.acl) et passé au renderer / rendu dans le cœur.
