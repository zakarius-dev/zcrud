ZSyncableRepository

ZSyncableRepository<T extends ZEntity> class abstract

Contrat abstrait d'un dépôt synchronisable : un ZRepository enrichi d'une unique méthode sync.

Frontière entre le comment et le quand : sync est un appel one-shot (pull + merge Last-Write-Wins + propagation bornée). Le quand (login/reconnexion débouncée) et le pilotage d'un ensemble de dépôts enregistrés appartiennent à ZSyncOrchestrator — hors de ce port.
