ZEditionSectionStyle

ZEditionSectionStyle class

Style déclaré d'une ZEditionSection — un objet de style nommé, pour l'en-tête (fond, filet supérieur, rayon, typographie, chevron) et pour le corps (filet vertical côté début le long des champs).

Chaque propriété est nullable et null par défaut : une propriété non déclarée conserve le rendu natif, à l'identique. Aucune couleur, aucun glyphe n'est imposé par le socle — tout vient de cette déclaration ou du thème ambiant.

Déclarer un style (même vide) rend la section en bloc (voie groupée du formulaire) : les décorations et le filet n'existent que là. Les sections sans style ni icône conservent leur voie de rendu d'origine.
