Copie de l'onglet avec les champs fournis remplacés (les autres inchangés).

Sert aux assembleurs : envelopper la vue d'un onglet (pour y déposer une portée, une ACL, une politique de requête) sans avoir à recopier à la main les huit autres déclarations — recopie où l'on oublie tôt ou tard celle qui vient d'être ajoutée.
