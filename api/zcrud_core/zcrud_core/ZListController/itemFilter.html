itemFilter

itemFilter property

bool Function(T item)? itemFilter
final

Post-filtre d'écran : dernier mot sur ce qui est listé, écrit sur l'entité T (null = aucun, défaut).

Appliqué aux entités lues, après la lecture de la source et avant la projection en lignes, donc avant la recherche, le tri et la pagination : une page pleine reste pleine. Il ne peut que restreindre — une entité que la requête n'a pas ramenée ne peut pas réapparaître.

Le déclarer impose la voie mémoire (voir le constructeur) : un prédicat Dart ne se traduit dans aucun langage de requête.
