ZDerivationEngine

ZDerivationEngine class

Exécute les ZDerivation d'un ensemble de ZFieldSpec sur un ZFormController.

Cycle de vie possédé par l'appelant : ZDerivationEngine(...) puis dispose (fait par DynamicEdition). dispose retire tous les listeners posés — aucun listener fuité (prouvé par test).
