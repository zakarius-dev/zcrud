acl filtre les actions du mode compact. null (défaut) ⇒ l'ACL du ZcrudScope ambiant est consultée ; sans scope, le repli est refusant (ZDenyAllAcl) : aucune action d'item n'est offerte. collectionId est transmis à ZAcl.can(..., collectionId:) ; itemTitleBuilder dérive le titre du dialog / résumé de ligne.
