selectTileBorderColor

selectTileBorderColor property

Color? selectTileBorderColor
final

Teinte de la bordure du déclencheur de sélection, pour toute l'app. null ⇒ le consommateur applique son rôle (ColorScheme.outlineVariant, celui de Card.outlined) — jamais un littéral (invariant FR-26).

lerp par _lerpNullableColor et non Color.lerp : Color.lerp(null, c, t) matérialise c dès t > 0 et peindrait une bordure par-dessus le rôle de repli du consommateur pendant la transition de thème (précédent exact : editionSheetBorderColor).

Ce jeton existe parce que la référence de l'hôte prime sur CardThemeData : le présentateur pose un shape: explicite pour tenir sa fidélité, donc cardTheme.shape ne peut PAS servir de canal. Le jeton est le seul chemin app-scale restant.
