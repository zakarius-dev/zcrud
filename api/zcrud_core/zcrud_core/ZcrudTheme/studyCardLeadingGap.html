studyCardLeadingGap property

double? studyCardLeadingGap
final

ÉCART entre la tuile d'icône de tête et le titre, dans les cartes d'étude par défaut. null ⇒ 16 (référence historique).

Ne concerne QUE les cartes par défaut : la primitive de base ZStudyToolsItemCard garde son écart historique gapM pour les hôtes qui la composent eux-mêmes (neutralité — cf. son slot leadingGap).

Ce token existe parce que cet écart ridait gapM, que l'hôte règle déjà pour le padding de carte (12) alors que la référence demande 16 : aucune valeur de gapM ne pouvait satisfaire les deux.
