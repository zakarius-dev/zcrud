booleanPillActiveColor property

Color? booleanPillActiveColor
final

Teinte de la piste à l'état true. null ⇒ ColorScheme.primary.

Le rendu historique peint un vert (kSuccessColorLight, #2E7D32) : Material 3 n'a pas de rôle « succès », et l'inventer exigerait un littéral (interdit par l'invariant FR-26). La voie exacte pour ce vert est donc la clé sémantique ZBooleanConfig.activeColorKey résolue par ZcrudScope.colorKeyResolver — ce jeton n'en est que le repli d'échelle thème.

lerp par _lerpNullableColor et non Color.lerp : Color.lerp(null, c, t) matérialise c dès t > 0 et peindrait la piste par-dessus le rôle de repli du consommateur pendant la transition (précédent exact : stepperRailColor).
