ZColumnOverride

ZColumnOverride class

Réglages d'une colonne précise, appliqués par deriveColumns par-dessus ce que le schéma dicte.

Le schéma reste la source de vérité : cet objet ne sert qu'à ce qui n'est pas dérivable d'une déclaration de champ — l'encombrement voulu à l'écran, une devise portée par une autre colonne, un format qui a besoin de toute la ligne. Tout champ omis laisse la valeur dérivée intacte.

ZColumnPolicy(
  overrides: {
    'amount': const ZColumnOverride(
      minWidth: 120,
      currency: ZCurrencyFormat(codeField: 'currency', fallbackCode: 'XOF'),
    ),
  },
);
