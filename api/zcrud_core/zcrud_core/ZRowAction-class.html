ZRowAction

ZRowAction<T extends ZEntity> class

Modèle d'action de ligne neutre et générique <T>.

Porte le handler typé onInvoke(context, entity) + la permission requise (requiredPermission, filtrée par ZAcl, AD-16) + les métadonnées d'UI. Se résout par ligne en un ZResolvedRowAction via resolve.
