DynamicEdition

DynamicEdition class

Assemble un formulaire d'édition réactif par tranche depuis un controller et la liste des fields connus, regroupés en sections visuelles.

manageVisibility → bool
Pilotage de visibleFields (imbrication de steppers) : quand true (défaut, comportement inchangé), ce formulaire GÈRE controller.visibleFields (amorçage + souscription aux champs de garde + setVisibleFields). Quand false, il n'écrit JAMAIS visibleFields et ne s'abonne PAS aux gardes : il rend passivement l'intersection de controller.visibleFields avec ses fields. Sert le nesting de steppers où un unique propriétaire (le stepper RACINE) écrit la fenêtre = union du chemin actif (invariant AD-2, single-writer) ; les zones d'étape imbriquées ne se battent alors jamais sur visibleFields.
