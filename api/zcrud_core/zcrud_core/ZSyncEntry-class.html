ZSyncEntry

ZSyncEntry<T extends ZEntity> class

Value object immuable appariant une entité T et son ZSyncMeta hors-entité (la clé LWW updatedAt + le drapeau isDeleted).

Transporte les tombstones : une entrée soft-deletée reste un ZSyncEntry valide (isDeleted == true, entity décodée). C'est précisément ce qui permet au merge LWW de propager une suppression d'un côté à l'autre — impossible via getAll/pull qui excluent les soft-deletés.

Dart pur (AD-5) : aucun type backend (Box/Timestamp/…) — uniquement T (contraint ZEntity) et ZSyncMeta (ISO-8601, snake_case).
