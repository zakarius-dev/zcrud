Propagation PAR LOT BORNÉE (AD-9) d'un changeset d'entries (gagnants locaux d'un merge), chacune écrite verbatim (méta préservée, jamais now()).

La borne de découpage (taille sûre sous la limite du backend) est backend-spécifique et vit exclusivement dans l'adaptateur (zcrud_firestore) — jamais dans ce port neutre (AD-5). Chaque lot est committé atomiquement (aucune écriture partielle non-commit). Une liste vide → Right(unit) (no-op). Erreur distante → Left(ZServerFailure).
