ZFieldChoice

ZFieldChoice class

Une option {value, label} proposée à la sélection.

Type-valeur const pur-données (lisible par ConstantReader par le générateur) :

  • value : valeur métier stockée (opaque, Object?).
  • label : libellé d'affichage (clé l10n ou littéral ; résolu côté UI).
  • subtitle : sous-titre optionnel par option (défaut null ⇒ aucune ligne secondaire).
  • disabled : option désactivée (non sélectionnable mais visible/ accessible ; défaut false).

Statique seulement : les options issues d'une source dynamique (relation / dépôt de choix) sont câblées au runtime, pas ici.
