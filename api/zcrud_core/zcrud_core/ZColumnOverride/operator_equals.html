Égalité de valeur sur les réglages déclaratifs uniquement.

formatWithRow est une fonction : deux closures écrites à l'identique ne sont jamais égales en Dart, et deux instances créées dans un build le seraient encore moins. La faire entrer dans l'égalité rendrait toute politique perpétuellement différente d'elle-même et priverait le rendu de sa mémoïsation. Elle en est donc exclue — même règle que ZListColumn.format et ZFieldSpec.
