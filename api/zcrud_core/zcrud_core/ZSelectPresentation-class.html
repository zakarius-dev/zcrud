ZSelectPresentation

ZSelectPresentation class

DTO NEUTRE présenté au seam. Ne porte QUE des données — jamais le ZFormController (invariant AD-2) ni aucun type d'un présentateur concret.

Suffisant pour select/radio/checkbox/relation ; extensible additivement (aucune montée de version requise).

Où vivent choiceBuilder et optionsLoader : ZFieldSpec est const/sérialisable et les invariants AD-3/AD-14 interdisent d'y loger une closure. Ils sont donc alimentés par un paramètre de widget (ZSelectFieldWidget/ZRelationFieldWidget, tous deux publics), et pas par le dispatcher déclaratif : celui-ci exigerait un registre injecté au scope + une clé de configuration, surface publique que ce seam n'expose pas en l'absence de besoin démontré.
