ZSyncRunReport

ZSyncRunReport class

Résultat immuable d'un cycle de synchronisation best-effort exécuté par ZSyncOrchestrator.

Invariant : attempted == succeeded + failed. Un cycle sauté (gate désactivé, hors-ligne, registre vide) est représenté par ZSyncRunReport.empty (attempted == 0).

Pur-Dart (AD-5) : aucune dépendance Flutter/backend — l'égalité de liste est implémentée localement (_listEquals) pour ne pas importer foundation.
