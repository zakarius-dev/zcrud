Produit les octets du fichier pour la request — colonnes dérivées et lignes telles qu'elles sont affichées.

title est le titre de l'écran, quand le format sait en faire quelque chose (un en-tête de document PDF, le nom d'une feuille de calcul) ; les formats qui n'en ont pas l'usage l'ignorent.

resolveHeader résout la clé l10n d'un en-tête de colonne sans BuildContext (l'export est headless) ; omis, l'en-tête est écrit tel quel.

Ne doit pas lever : un échec s'exprime par Left(ZFailure).
