ZCodecRegistry

ZCodecRegistry<T extends Object> class

Registre générique String kind → T (entrée = un codec ou couple de fonctions). Instanciable et isolé : deux instances ne partagent aucun état, ce qui isole une app d'une autre et un test du suivant.
