dropRegionRenderer

dropRegionRenderer property

ZDropRegionRenderer? dropRegionRenderer
final

Seam de zone de dépôt NATIVE (défaut null → ZNoDropRegionRenderer, qui rend le contenu SANS capacité de dépôt).

Capacité DISTINCTE du réordonnancement : recevoir un fichier du système ou d'une autre application. Elle est isolée dans le satellite opt-in zcrud_dnd parce que son backend impose une CHAÎNE DE BUILD NATIVE à toute application consommatrice — coût qu'un hôte sans besoin de dépôt ne doit pas payer. Jamais un singleton statique mutable.
