iconResolver property

ZAdornmentIconResolver? iconResolver
final

Résolveur d'icône d'ornement host-fourni (défaut null → le cœur retombe sur sa table Material bornée par défaut, puis null si la clé reste inconnue — AD-10). Traduit une clé neutre (String) de ZFieldAdornment.icon(key) en IconData sans que le domaine ne porte jamais d'IconData (AD-3/AD-14). Instanciable, injecté (jamais un singleton).
