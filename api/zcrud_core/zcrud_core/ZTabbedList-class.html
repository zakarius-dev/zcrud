ZTabbedList class

Onglets de catégorisation : TabBar (N onglets) + TabBarView (une liste indépendante par onglet, état préservé au switch).

Constructors

ZTabbedList({required List<ZListTab> tabs, int initialIndex = 0, ValueChanged<int>? onTabChanged, bool isScrollable = false, Widget? header, ValueNotifier<int>? activeIndexNotifier, Key? key})
Construit les onglets à partir de tabs. initialIndex fixe l'onglet actif initial ; onTabChanged est notifié à chaque changement d'onglet ; isScrollable rend la barre défilante (nombreux onglets) ; header pose un widget partagé au-dessus de la barre d'onglets ; activeIndexNotifier suit l'index de l'onglet actif.
const
