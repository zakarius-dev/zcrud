ZValidatorSpec

ZValidatorSpec class

Spécification const d'un validateur de champ (pur-données).

Chaque variante est construite par un constructeur de fabrique nommé const ; les paramètres non pertinents restent null. errorText (optionnel, partout) porte un message d'erreur littéral ou une clé l10n (résolu côté UI en E3).
