Supprime en lot (best-effort) les éléments sélectionnés via repository.softDelete (AD-9/AD-11). Chaque Left(ZFailure) est remonté à onFailure sans throw ; les id supprimés avec succès sont retirés de la sélection (les échecs y restent). onSuccess est appelé si tous les soft-delete ont réussi.

Atomicité : best-effort — une transaction atomique multi-document est backend-spécifique, non garantie ici.

Future<void> softDeleteSelected<T extends ZEntity>(
  ZRepository<T> repository, {
  void Function(ZFailure failure)? onFailure,
  void Function()? onSuccess,
}) async {
  if (_disposed) return;
  final ids = _selected.value.toList(growable: false);
  final succeeded = <String>{};
  var allOk = true;
  for (final id in ids) {
    final result = await repository.softDelete(id);
    result.fold(
      (failure) {
        allOk = false;
        onFailure?.call(failure);
      },
      (_) => succeeded.add(id),
    );
  }
  if (_disposed) return;
  if (succeeded.isNotEmpty) {
    _commit(<String>{..._selected.value}..removeAll(succeeded));
  }
  if (allOk) onSuccess?.call();
}
