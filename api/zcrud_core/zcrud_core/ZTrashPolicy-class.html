ZTrashPolicy

ZTrashPolicy class

Gestes de corbeille voulus par la déclaration.

Par défaut, les trois gestes sont offerts (full) : la corbeille complète est le comportement attendu, et retirer un geste est le cas particulier.

// Corbeille consultable et restaurable, mais rien ne s'y détruit :
const ZTrashPolicy(purge: false)
