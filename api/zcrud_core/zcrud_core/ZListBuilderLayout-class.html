ZListBuilderLayout

ZListBuilderLayout class final

Vue liste : rend un ListView.builder dans le cœur (Material-free), une entrée par ligne. N'exige AUCUN renderer.

Deux façons de décrire l'entrée, au choix :

  • itemBuilder — la ligne neutre (ZListRow + colonnes) ;
  • entityBuilder — l'entité résolue, forme typée obtenue par ZListBuilderLayout.forEntity ou posée par un assembleur via withEntityTiles.

Quand les deux sont présents, entityBuilder l'emporte tant que l'entité de la ligne est résolue (seam DynamicList.entityFor) ; sinon le rendu retombe sur itemBuilder. Aucun des deux ⇒ entrée vide : la vue attend alors qu'un assembleur lui pose sa tuile.
