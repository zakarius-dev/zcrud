ZSubListConfig

ZSubListConfig class

Config triviale pur-cœur des champs sous-liste (subItems) et item dynamique (dynamicItem).

itemFields est le sous-schéma const d'un item (chaque item est édité par un sous-formulaire imbriqué). reorderable active le réordonnancement (monter/descendre) de la sous-liste ; sans effet pour dynamicItem (cardinalité ≤ 1).

Additif, rétro-compat : displayMode choisit inline (défaut) vs compact ; summaryFields liste ordonnée de name de sous-champs projetés en colonnes/valeurs de résumé en mode compact (pur-données ; un titre/rendu personnalisé passe par un seam de présentation, jamais par une closure dans le domaine). Le réordonnancement reste une notion inline (reorderable est sans effet en mode compact).
