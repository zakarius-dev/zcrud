ZSelectChoiceBuilderRegistry

ZSelectChoiceBuilderRegistry class

Registre des ZSelectChoiceBuilders, indexé par une clé déclarative.

Un enfant consulte d'abord ses entrées puis son parent. Il peut donc ombrer légitimement une clé parent, mais une double inscription locale lève explicitement une ZDuplicateRegistrationError. Le lookup défensif retourne null pour permettre au widget de retomber sur son rendu natif.
