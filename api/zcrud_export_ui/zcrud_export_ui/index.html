zcrud_export_ui library

Barrel d'API publique de zcrud_export_ui — satellite plateforme d'export.

zcrud_export reste PUR (bytes in/out) ; ce package porte les maillons de PLATEFORME :

  • ZFlutterMathLatexRasterizer : impl concrète du port pur ZLatexRasterizer (rendu flutter_math_fork hors écran → PNG) ;
  • ZPdfShareService / ZPdfPreview : preview / impression / partage de bytes PDF via printing.

Isolation (invariant AD-8) : ce barrel n'exporte AUCUN symbole printing / pdf / flutter_math_fork. L'API publique est 100% Uint8List (les types PdfPageFormat / Math / … sont absorbés dans lib/src/). Gardé par un test de confinement dédié.

API publique = ce barrel ; implémentation sous lib/src/.
