maxWidth

maxWidth constant

double const maxWidth

Plafond absolu de largeur (dp).

Ce n'est pas un choix de goût : c'est le défaut de Flutter lui-même. flutter/lib/src/material/bottom_sheet.dart, _BottomSheetDefaultsM3 : constraints => const BoxConstraints(maxWidth: 640.0). Un presenter qui poserait ses propres constraints non-null (maxWidth: double.infinity) écraserait ce plafond : sur un écran de 1600 dp la feuille ferait 1600 dp de large, alors qu'une showModalBottomSheet nue en ferait 640. Le plafond restaure le défaut M3 au lieu de le contredire.

Effet de min(largeur * 0,9, 640) :

Écran Ratio seul Retenu Commentaire
360 324 324 marge visible (18 dp de part et d'autre)
400 360 360 marge visible
700 630 630 ratio encore actif
1600 1440 640 plafond M3 — 1440 dp serait illisible
