ZAdaptivePresenterDefaults

ZAdaptivePresenterDefaults class abstract final

Bornes d'écran par défaut de la présentation adaptative (dp) — publiques pour qu'un binding qui implémente le port ZFormPresenter puisse s'aligner sur la source plutôt que de la recopier localement (dialog ~ largeur bornée, sheet ~ 90 % hauteur, dérivées de MediaQuery.sizeOf quand maxWidth/maxHeight ne sont pas fournis).
