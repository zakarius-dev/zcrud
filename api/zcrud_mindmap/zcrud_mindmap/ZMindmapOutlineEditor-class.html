ZMindmapOutlineEditor

ZMindmapOutlineEditor class

Éditeur outline indenté et éditable d'une forêt de cartes mentales.

Par défaut, crée et possède un ZMindmapOutlineController interne (initialisé depuis roots) qu'il dispose. Un contrôleur peut être injecté via controller (l'appelant en garde alors la propriété et le cycle de vie).
