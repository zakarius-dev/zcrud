Nombre de nœuds que deleteNode retirerait pour id — racine du sous-arbre comprise. 0 si l'id est introuvable.

Permet à un hôte d'annoncer l'ampleur AVANT de supprimer (« ceci supprimera 12 nœuds »), au lieu de la découvrir après coup.

Implementation

int subtreeSize(String id) {
  final node = ZMindmapTreeOps.findNode(_forest, id);
  if (node == null) return 0;
  var n = 0;
  void visit(ZMindmapNode x) {
    n++;
    for (final child in x.children) {
      visit(child);
    }
  }

  visit(node);
  return n;
}
