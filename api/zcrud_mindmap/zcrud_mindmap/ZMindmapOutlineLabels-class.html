ZMindmapOutlineLabels class

Bundle immuable de libellés a11y pour ZMindmapOutlineEditor.

Chaque champ a un repli neutre non-nul. Toutes les chaînes UI de l'éditeur passent par cet objet : le widget ne code aucune chaîne en dur.
