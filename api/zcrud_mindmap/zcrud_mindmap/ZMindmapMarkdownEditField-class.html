ZMindmapMarkdownEditField

ZMindmapMarkdownEditField class

Adaptateur d'édition rich-text d'un champ de nœud, adossé au slot AD-4.

Usage app : ZMindmapOutlineEditor(editFieldBuilder: ZMindmapMarkdownEditField.builder(slotKey: 'rich_delta')). Sans injection, l'outline retombe sur son TextField texte brut (aucune régression).

slotKeyFor(String baseSlotKey, ZMindmapEditFieldKind kind) → String
Slot AD-4 effectif selon kind : content → baseSlotKey (symétrie EXACTE avec le rendu ZMindmapMarkdownContent) ; label → un slot voisin distinct ('${baseSlotKey}__label') pour ne jamais entrer en collision avec le payload content. node.label/content restent plain quoi qu'il arrive.
