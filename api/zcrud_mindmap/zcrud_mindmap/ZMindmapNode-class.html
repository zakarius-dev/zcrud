ZMindmapNode

ZMindmapNode class

Nœud d'arbre de carte mentale, immuable par convention.

  • topologie par children imbriqués (nesting) ;
  • level = cache de profondeur dénormalisé (racine = 0), recalculé systématiquement par ZMindmapTreeOps à chaque reparentage (ne jamais faire confiance au level d'un nœud déplacé) ;
  • content = texte brut multiligne (PAS markdown — le rendu riche est une extension pluggable) ;
  • slots d'extension invariant AD-4 via ZExtensible (extension versionnée + extra échappatoire non typée, round-trip des clés inconnues du cœur).
