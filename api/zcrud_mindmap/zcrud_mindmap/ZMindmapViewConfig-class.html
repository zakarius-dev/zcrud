ZMindmapViewConfig

ZMindmapViewConfig class

Configuration immuable de layout structurel de la vue (AD-13/FR-26).

Ne porte aucune couleur (les couleurs proviennent de ZcrudTheme) : uniquement des constantes géométriques admissibles (bornes de zoom, taille de cellule graphite, pas d'indentation, cible tactile minimale ≥ 48 dp).
